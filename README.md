# Duitku TypeScript SDK

SDK TypeScript untuk integrasi payment gateway Duitku, kompatibel dengan **Node.js** dan **Bun**.

> ⚠️ **Work in Progress** — Sedang dalam tahap rewrite dari [duitku-php](https://github.com/duitkupg/duitku-php).

## Installation

```bash
npm install duitku
# atau
bun add duitku
```
